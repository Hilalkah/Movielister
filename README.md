# Movie Lister 🎬

Track your movie watchlist with ease!

## Features
- ✅ Add movies from text/clipboard
- ✅ Parse movie titles with notes
- ✅ Separate watched/unwatched lists
- ✅ Search movies on Google
- ✅ Collapsible lists

## Tech Stack
- SwiftUI
- iOS 17.6+
- MVVM Architecture
